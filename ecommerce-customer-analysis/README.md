# Data Analysis Results

Question 1: Which customer segment has the highest average total spending?

The analysis shows that Premium customers have the highest average total spending.

Premium: $50,461.56
Consumer: $50,451.87
Small Business: $50,190.56
Enterprise: $49,120.29

Answer: Premium customers have the highest average total spending at approximately $50,461.56.

Question 2: Which customer segment has the highest number of customers?

The analysis shows that Consumer has the highest number of customers.

Consumer: 22,507
Premium: 12,423
Small Business: 9,979
Enterprise: 5,091

Answer: Consumer has the highest number of customers with 22,507 customers.
